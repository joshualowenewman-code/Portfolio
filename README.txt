resume.html expects two files in this exact folder:

  resumes/resume-designed.pdf   → the "Designed Resume" card
  resumes/resume-ats.pdf        → the "ATS-Friendly Resume" card

Just drag your real PDF files into this folder in VS Code and name
them exactly as above. No other code changes are needed — clicking
either the thumbnail image OR the "Download PDF" button on each card
already points at these paths and will download the file once it's here.

If you'd rather use different filenames, that's fine too — just update
the two matching href="resumes/..." attributes in resume.html (one on
the image link, one on the button) so they point at your actual filename.

You can delete this file once your real PDFs are in place.
